## Required record for every asset

Before marking an entry as verified, record:

- Exact file path (or a clearly defined group of files).
- Creator / author or original source URL.
- Exact license name and version, or written permission.
- Required attribution text and link, if any.
- Any restrictions relevant to modification, commercial use, redistribution, or sublicensing.
- Evidence location (license file, source page, purchase receipt, or permission record).

Do not infer a license from the fact that a file is publicly accessible, included in a repository, or described as royalty-free. Do not apply the repository MIT license to an asset unless its rights holder has explicitly granted that license.

## Release gate

All shipped assets must have verified rights for the intended distribution before a public release is tagged or announced. If provenance or permission cannot be established, replace the asset with an original or properly licensed alternative, or exclude it from the release.

New assets must be recorded here in the same pull request that adds them.
